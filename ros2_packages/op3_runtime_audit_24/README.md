# Audit runtime OP3 24 slot

Package baca-saja untuk memeriksa log mentah, hash label, dan menghasilkan tabel serta grafik baru. Tidak mengirim perintah ke robot. Dari root repository: `PYTHONPATH=ros2_packages/op3_runtime_audit_24 .venv-op3-pytorch/bin/python -m op3_runtime_audit_24.audit`. Output dibuat di direktori baru dan tidak menimpa output audit sebelumnya.
