# T43: perekaman berjalan dengan guard

Package ini memakai `Guard` dari `op3_equal_live_walk` tanpa mengubah package lama. Setelah telemetry kepala, publisher gait, proses preview, dan log detector hidup, ia mengirim start dan menunggu ack. Hanya sesudah ack, ia menjalankan capture 1–50 frame tiap ±1 detik (default 50). Gait berhenti saat capture selesai atau maksimum 63 detik, atau lebih cepat bila telemetry/preview hilang atau kepala menyimpang lebih dari dua count. Semua run, frame, dan log memakai direktori baru. `stop` dikirim saat keluar/terjadi kesalahan; ack stop dan gerak sendi tetap perlu diaudit. Guard tidak membuktikan bahwa jendela X11 benar-benar dirender lancar pada setiap frame, dan kontrol ini bukan jaminan nol gerakan mekanis kepala. Operator harus siap mendampingi dan menghentikan robot melalui prosedur normal.
