# Peninjauan manual 120 frame dari tiga kelompok

Atas instruksi terbaru pengguna, peninjauan manusia dimulai setelah **120 dari 240 frame** terkumpul. Instruksi sebelumnya untuk menunggu seluruh 240 frame digantikan oleh permintaan ini. Peninjau manusia adalah `bhre`; jendela lokal SSH-X dibuka dengan [package peninjau gabungan](../../../ros2_packages/op3_multi_session_reviewer/README.md). Package ini memakai `op3_label_reviewer` sebagai shared code dan tidak mengubah package lama.

Urutan global pada jendela: frame 1–40 = [robot + bola](../../../data/op3_camera_eval/sessions/20261021_robot_ball_01/images/), 41–80 = [robot + gawang](../../../data/op3_camera_eval/sessions/20261021_robot_gawang_01/images/), 81–120 = [gawang + bola](../../../data/op3_camera_eval/sessions/20261021_gawang_ball_01/images/). Semua gambar mentah 640×480 tetap di sesi masing-masing.

Label otomatis dibuat dari checkpoint KD `models/weights/kd_student_best.pt` pada `imgsz=640`, `conf=0.25`, `iou=0.45` dan disimpan terpisah dalam `labels_auto/`. Draf berjumlah 40 file untuk setiap sesi. Jumlah kotak draf: robot + bola = 40 `ball`, 34 `robot`; robot + gawang = 27 `robot`, **0 `gawang`**; gawang + bola = 40 `ball`, 40 `gawang`. Ini keluaran model, bukan label manusia. Peninjau perlu menambah kotak yang terlewat, terutama gawang pada frame 41–80, menghapus prediksi palsu, dan menyesuaikan kotak/kelas pada setiap gambar.

`S` menyimpan hanya frame yang sedang dilihat ke `labels_reviewed/frame_*.txt` dan menulis `review_log.jsonl` pada sesi asal; `N`/panah kanan maju, `P`/panah kiri mundur, klik kotak lalu `Delete` untuk menghapus, tarik pada area kosong untuk menambah, `0`/`1`/`2` memilih `ball`/`gawang`/`robot`, `R` membatalkan edit belum tersimpan, dan `Q`/Esc keluar. Setelah frame 40 dan 80, `N` otomatis maju ke sesi berikutnya. Jika jendela tertutup, perintah pada README package dapat dibuka lagi dengan `--start N` untuk melanjutkan dari nomor global N.

**Status setelah peninjauan: 120/120 frame telah disimpan oleh `bhre`.** Setiap sesi memiliki 40 JPEG, 40 file `labels_reviewed/frame_*.txt`, dan log yang mencakup semua 40 nama frame. Jumlah baris log berturut-turut 40, 41, dan 41 karena frame 7 pada kelompok robot + gawang serta frame 2 pada kelompok gawang + bola disimpan ulang. Seluruh label memakai kelas 0–2 dan koordinat YOLO yang valid; tidak ada nama frame hilang atau file label kosong.

Distribusi label akhir: robot + bola = 40 kotak `ball` dan 40 `robot`; robot + gawang = 40 `robot` dan 40 `gawang`; gawang + bola = 40 `ball` dan 40 `gawang`. Ini merupakan hitungan label yang disimpan, bukan ukuran akurasi model. Waktu penyimpanan tercatat 21 Oktober 2026, 14:47:07–15:36:31 WIB.

**Audit visual lanjutan menemukan perbedaan batas kotak `gawang`.** Pada sampel kelompok robot + gawang, kotak mencakup seluruh rangka gawang. Pada sampel kelompok gawang + bola, kotak hanya mencakup tiang kanan; lebar median kotak `gawang` masing-masing 0,288 dan 0,102 dari lebar gambar. [Contoh perbandingan lokal](../../../data/op3_camera_eval/sessions/20261021_gawang_ball_01/audit_kotak_gawang_20261021.jpg) menampilkan frame 1 dari kelompok robot + gawang serta frame 1, 20, dan 40 dari kelompok gawang + bola. Kotak manusia **tidak diubah secara otomatis**. Peninjau perlu memeriksa ulang 40 frame gawang + bola dan menerapkan definisi kotak yang sama sebelum label dipakai sebagai ground truth evaluasi. Frame gawang + bola 30–32 juga menampilkan bola yang terpotong tepi bawah, sedangkan frame 33 menampilkan tangan yang sebagian menutupi bola; pertahankan atau keluarkan frame tersebut berdasarkan aturan evaluasi yang ditetapkan secara eksplisit.

Karena konsistensi kotak masih perlu dikonfirmasi, akurasi, recall, precision, dan mAP dari tiga kelompok ini **belum dihitung**. Gambar, label, log, dan contoh audit tetap lokal sesuai instruksi prompt eksperimen.
