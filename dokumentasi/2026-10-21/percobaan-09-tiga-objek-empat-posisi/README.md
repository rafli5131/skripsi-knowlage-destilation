# Percobaan 09 — tiga objek pada empat posisi

Pengguna meminta kelompok terakhir 40 frame dibagi menjadi **empat sesi × 10 frame**, dengan kesempatan mengubah susunan bola, gawang, dan robot di antara sesi. Agen memberi tahu operator setelah tiap 10 frame dan menunggu konfirmasi posisi berikutnya sebelum merekam. Tidak ada perintah servo, gait, atau motor. Kondisi servo sesi ini belum diverifikasi dan dicatat `unknown`. Commit runtime `0c14591`; kamera `/thesis/image_raw` 640×480, deteksi KD PyTorch FP32 CPU live pada `/vision/debug_image`, `run_id=20261021_all_three_positions_live`.

Keempat sesi selesai dengan **40/40 gambar mentah** dan **40 hash berbeda**. Jendela deteksi live tetap terbuka selama pengambilan. [Grafik interval dan deteksi per posisi](grafik_interval_dan_deteksi_per_posisi.png) membandingkan jeda antar-frame dan persentase frame live yang diberi kotak oleh model. Jumlah frame live yang diproses selama jendela capture posisi 1–4 berturut-turut 114, 111, 81, dan 128. Model memberi kotak `ball` pada 99,1%, 99,1%, 100%, dan 100% frame live; `gawang` pada 16,7%, 0%, 0%, dan 100%; `robot` pada 0%, 100%, 100%, dan 100%. Ini **bukan recall atau akurasi** karena belum dibandingkan dengan label manusia dan detektor memproses lebih banyak frame daripada 10 JPEG per posisi. [Log live](../../../runs/op3_pytorch/20261021_all_three_positions_live.csv) menyimpan metrik per frame; tidak digunakan sebagai benchmark runtime terpisah karena kamera dan viewer aktif bersamaan.

Enam kelompok kini menyediakan **240/240 frame mentah/kandidat**: kelompok bola bergerak memakai 32 frame asli dan 8 frame pengganti untuk kandidat deteksi per frame. Keempat sesi posisi ini tetap terpisah agar tiap susunan dapat ditinjau sendiri. Seluruh 120 frame dari tiga kelompok terakhir masih memerlukan peninjauan manusia; 120 frame dari tiga kelompok pertama sudah ditinjau, tetapi [audit sebelumnya](../percobaan-06-peninjauan-manual-120-frame/README.md) mencatat batas kotak `gawang` yang perlu diseragamkan.

Atas permintaan berikutnya, [10 frame posisi kelima](../percobaan-10-posisi-tambahan-10-frame/README.md) direkam **sebagai tambahan terpisah** dari target 240 frame.

Frame kelompok ini belum memiliki label hasil peninjauan manusia. Jangan menganggap deteksi live sebagai ground truth atau menghitung akurasi dari label yang belum diperiksa. Gambar dan log robot tetap lokal sesuai prompt eksperimen.
