# Percobaan 31 — KD Hybrid berjalan, tiga ulangan

Pada **3 November 2026**, operator meminta tiga ulangan berjalan dengan model KD Hybrid full seed 1337 dan preview SSH-X aktif agar objek bisa diatur serta diverifikasi sebelum **setiap** ulangan. Semua gait menerima ack start/stop; tidak ada perintah gerak kepala ID 19/20. [Ringkasan tiga run](02-kd-hybrid/README_ID.md) memuat tabel hasil, grafik HD berlabel sumbu, cakupan keluaran, serta batas audit. [Ulangan 1](02-kd-hybrid/walk-u1/README_ID.md), [ulangan 2](02-kd-hybrid/walk-u2/README_ID.md), dan [ulangan 3](02-kd-hybrid/walk-u3/README_ID.md) masing-masing memiliki overlay kamera, telemetry, grafik, tabel, dan JSON guard.

Sebelum pengujian, OpenCR dilaporkan menerima 12,6–12,7 V tetapi bus servo mati. Dengan robot ditopang operator, bus diaktifkan, 20 servo diperiksa tanpa hardware error, dan manager dijalankan dengan init pose otomatis mati. [Screenshot persiapan u1](00-persiapan/preview_setelah_tata_u1.png), [u2](00-persiapan/preview_sebelum_u2.png), dan [u3](00-persiapan/preview_sebelum_u3.png) menunjukkan ketiga objek sebelum gait. Posisi kepala tidak berubah saat startup/pemetaan modul. Daya, pembacaan, dan perubahan kondisi tercatat pada [log sesi](log_penyimpangan.md).

**Status kampanye empat model:** bersama [sembilan run 2 November](../../2026-11-02/percobaan-30-uji-live-setara-empat-model/README_ID.md), kini **12/24 slot** telah terukur. Tabel dan [grafik matriks 24 slot](../../2026-11-02/percobaan-30-uji-live-setara-empat-model/05-ringkasan/grafik_24_run_ulangan_1_2_3_hd.png) diperbarui lintas hari; **12 slot Supervised dan KD murni** masih belum diukur. T36/T37 final tetap menunggu seluruh run dan audit protokol. Output deteksi live bukan akurasi berlabel.

Preview KD Hybrid dinyalakan kembali setelah ulangan 3 dan pada pemeriksaan terakhir menerima frame baru. Proses dan kondisi robot harus dicek ulang sebelum pengujian berikutnya; gait sudah berhenti, manager dan torque tetap aktif pada akhir sesi ini.
