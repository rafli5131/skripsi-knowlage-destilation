## Arah penelitian

- Arah terbaru: menerapkan student YOLO hasil pure teacher-only Knowledge Distillation (KD) untuk deteksi bola, gawang, dan robot pada ROBOTIS OP3.
- Deployment yang direncanakan memakai PyTorch/Ultralytics dan checkpoint `.pt` pada CPU. OpenVINO, QAT, dan INT8 tidak termasuk metode deployment saat ini.
- Judul dan rumusan masalah final belum disahkan. Rumusan kerja mencakup mAP; precision, recall, F1; latensi dan FPS; serta utilisasi CPU dan RAM.
- Kelas dataset berurutan: `0=ball`, `1=gawang`, `2=robot`.

## Dataset dan protokol

- Benchmark utama menggunakan split resmi Roboflow train/val/test dari `advance_vision_human`, versi v1 (V1-Base). Split tidak dibagi ulang.
- Lisensi dataset tercatat CC BY 4.0; datasheet export menyebut 6.405 gambar, format anotasi YOLO, resize 640 × 640, tanpa augmentasi saat export. Draf proposal mencatat train 4.600, val 1.213, test 592; verifikasi kembali dengan fingerprint/manifest sebelum mengutip angka.
- TRAIN dipakai untuk training, VAL untuk pemilihan checkpoint dan konfigurasi, TEST untuk evaluasi akhir. Jangan memakai TEST untuk tuning.
- Audit menemukan kemiripan nama sumber/adegan lintas split. Ini membatasi klaim pada generalisasi level-gambar; jangan menyebutnya bukti bahwa semua gambar duplikat atau pasti terjadi kebocoran.
- Provenance teacher tidak lengkap: manifest teacher tidak mencatat versi dataset dan YAML training teacher lama tidak tersedia. Jangan mengklaim byte TRAIN/VAL teacher identik dengan Roboflow v1.

## Eksperimen KD yang sudah selesai

- Teacher: YOLO11n FP32 yang dibekukan. Student: arsitektur YOLO11 custom lebih kecil, random initialization, `pretrained=false`.
- Pure KD memakai distilasi fitur P3/P4/P5 dan output box/kelas teacher. Loss student KD tidak menggunakan label ground-truth, pseudo-label loss, QAT, atau INT8.
- Student supervised dengan arsitektur sama adalah kontrol terpisah dan menggunakan label TRAIN untuk loss.
- Enam run student selesai untuk pasangan metode dan tiga seed (`42`, `1337`, `2025`). Checkpoint student dipilih berdasarkan VAL sebelum evaluasi TEST terkunci.
- Checkpoint kandidat yang disimpan di repository: `models/weights/kd_student_best.pt` (seed 42). Hash dan manifest harus diperiksa sebelum menyatakan checkpoint sebagai hasil final deployment.
- Hasil analisis terkoreksi: mean TEST mAP50–95 pure KD `0,6630 ± 0,0108`; supervised `0,7225 ± 0,0035`. Hipotesis KD mengungguli kontrol supervised tidak didukung.
- Dibanding teacher, student KD memiliki parameter 68,71% lebih sedikit, ukuran checkpoint 65,20% lebih kecil, dan GFLOPs 62,64% lebih rendah. Student KD dan supervised memiliki arsitektur/parameter/FLOPs yang sama.
- Mean latensi median host NVIDIA L40: KD 25,01 ms, supervised 25,00 ms, teacher 25,72 ms. Angka ini bukan benchmark OP3.
- Sumber hasil utama: `artifacts/thesis_analysis_final_corrected/`, manifest evaluasi/benchmark, `PROTOKOL_EKSPERIMEN_SKRIPSI.md`, dan `README.md`. Draf proposal lama masih berfokus pada Advance Vision dan perlu diselaraskan sebelum menjadi proposal OP3 final.

## Rencana pengujian pada OP3

- Checkpoint belum diuji pada kamera atau runtime OP3 sampai tanggal memory ini.
- Pengujian langsung direncanakan dalam dua kondisi: `servo_idle` (robot menyala dan diam) dan `walking` (servo aktif/robot berjalan).
- Untuk setiap kondisi ukur latensi, FPS, utilisasi CPU, dan RAM dengan konfigurasi model/kamera yang sama; laporkan hasil masing-masing kondisi.
- Akurasi mAP/precision/recall/F1 yang tersedia berasal dari test set Roboflow. Uji live OP3 tanpa frame berlabel hanya mendukung pengukuran runtime dan observasi kualitatif, bukan klaim mAP khusus kamera OP3.
- Informasi terminal OP3 yang pernah dilaporkan: x86_64, Intel Core i5-1240P, Ubuntu 24.04.5, Python 3.12.3, ROS 2 Jazzy. Verifikasi ulang ketika integrasi dimulai.
- Detector harus membaca kamera dan menerbitkan hasil saja; tidak mengendalikan servo atau gait. Operator memulai/menghentikan kondisi berjalan.
