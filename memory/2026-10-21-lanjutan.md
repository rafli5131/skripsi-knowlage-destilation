# Memori proyek — lanjutan 21 Oktober 2026

Catatan ini memperbarui status lapangan setelah [`2026-10-21.md`](2026-10-21.md). Bagian catatan lama yang menyatakan belum ada uji kamera/label OP3 pada tanggal ini sudah **tidak berlaku**. Gunakan artefak yang ditautkan sebagai sumber angka, bukan ringkasan ini bila ada perbedaan.

## Tujuan dan batas kerja pengguna

- Penelitian adalah **Knowledge Distillation (KD)** untuk deteksi `ball`, `gawang`, dan `robot` pada ROBOTIS OP3, bukan “knowledge development”. Teacher adalah YOLO11n; student adalah YOLO11 kustom skala `t` (810.649 parameter), bukan YOLO11n standar. Objective utama KD murni *teacher-only* (`pure_v4`); student berarsitektur sama yang dilatih supervised adalah kontrol.
- Pengguna menampilkan deteksi live melalui **SSH-X**, tanpa web. Live camera menampilkan kotak, kelas, ID, dan confidence. Jangan menggerakkan robot hanya untuk uji deteksi/tracking gambar. Kode baru harus berada dalam **package baru**, boleh memakai kode package lama sebagai shared dependency, tanpa mengubah kode package lama.
- Pengguna ingin hasil sebelumnya tidak hilang. Workspace saat catatan ini dibuat memiliki banyak file eksperimen dan package **belum terlacak Git**; jangan menimpa/membersihkan data itu saat memperbarui repo. Tidak ada permintaan push pada tugas pembuatan memori/prompt ini.

## Data dan hasil yang sudah tersedia

- Dataset resmi Advance Vision/Roboflow v1: 4.600 TRAIN, 1.213 VAL, 592 TEST. Training utama teacher-only KD dan supervised memakai tiga seed berpasangan (42, 1337, 2025). Hasil TEST terkunci dan keterbatasan split/provenance ada di [`PROTOKOL_EKSPERIMEN_SKRIPSI.md`](../PROTOKOL_EKSPERIMEN_SKRIPSI.md) serta [`artifacts/thesis_analysis_final_corrected/`](../artifacts/thesis_analysis_final_corrected/). Rerata mAP50–95 TEST KD `0,6630 ± 0,0108`; supervised `0,7225 ± 0,0035`. KD **tidak** mengungguli kontrol supervised pada TEST ini. Benchmark NVIDIA L40 bukan pengukuran OP3.
- Frame kamera OP3 telah diambil dan ditinjau manusia (`bhre`). Evaluasi deteksi offline utama memakai **260 gambar**: 200 dengan target dan 60 negatif, 400 kotak GT. Set **50 gambar gawang parsial** disajikan terpisah karena definisi kotak berbeda. Pada set utama, student KD mAP50 `0,630`, mAP50–95 `0,422`; kontrol supervised `0,672` dan `0,419`. Kondisi satu lingkungan/hari menjadikannya eksploratif. Bukti dan batasan: [`percobaan 13`](../dokumentasi/2026-10-21/percobaan-13-evaluasi-deteksi-multi-sesi/README.md) serta [`percobaan 14`](../dokumentasi/2026-10-21/percobaan-14-audit-kesalahan-80-frame/README.md). - Uji live tracking terukur `20261021_tracking_live_01` memakai **student KD seed 42**, alias `op3_default`/`kd_seed42`, checkpoint [`models/weights/kd_student_best.pt`](../models/weights/kd_student_best.pt), SHA-256 `2da0c0e58a5c1884358fe814f8992cda19bb7b58f292edc15f53b9081b6129c3`. Varian model `kd`, CPU FP32, `imgsz=640`, confidence `0,25`, NMS IoU `0,45`, tracker **BoT-SORT**. Ini bukan teacher, bukan student supervised, dan bukan pilot `pure_weighted`.
