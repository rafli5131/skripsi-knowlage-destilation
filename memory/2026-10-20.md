# Memori kerja — 20 Oktober 2026

## Keputusan dan cakupan

- Pengguna menyetujui pilot KD murni teacher-only `pure_weighted` untuk melengkapi ablasi lab/server T04.
- Teacher YOLO11n dan student YOLO11 kustom skala `t` tetap sama. Data memakai split Roboflow resmi Advance Vision, dengan pemilihan model hanya pada VAL. TEST historis tidak dibuka ulang untuk memilih objective.
- Pilot memakai seed 42, maksimal 100 epoch, konfigurasi lain mengikuti baseline `pure_v4` seed 42.

## Yang dikerjakan

- Implementasi pembobotan lokasi head loss oleh skor kelas teacher maksimum ada di `scripts/kd_losses.py`, dipanggil dari `scripts/train_kd.py`; konfigurasi di `configs/kd_pure_weighted.yaml`. Teacher beku dan label TRAIN tidak masuk loss student.
- Pilot selesai 100 epoch, best checkpoint pada epoch 89: `runs/kd/yolo11_tiny_pure_weighted_pilot_seed42/weights/best.pt`. Manifest mencatat hash checkpoint, kode, dan fingerprint data.
- Tiga baseline `pure_v4` dan pilot dievaluasi ulang pada 1.213 gambar VAL dengan FP32 CPU server. Empat JSON ada di `runs/val_ablation/pure_weighted_20261020/`.
- T04 ringkasan dan per kelas diperbarui di `analisis_performa/tabel/`; indeks serta manifest kurasi lab/server diperbarui.

## Hasil dan keputusan

- VAL mAP50–95: `pure_weighted` seed 42 **0,5907**, `pure_v4` seed 42 **0,6826** (selisih **−0,0919**).
- Pada confidence >0,25, precision/recall/F1 makro pilot **0,0473 / 0,9906 / 0,0903**; baseline **0,7899 / 0,9623 / 0,8676**. Recall `gawang` naik **0,9752 vs 0,9494**, tetapi precision dan AP `gawang` turun.
- Berdasarkan kriteria mAP50–95 VAL yang ditetapkan sebelum pilot, `pure_v4` tetap model utama. Pilot adalah hasil ablasi negatif; tidak diteruskan ke tiga seed atau deploy OP3.
- T01–T14 lab/server lengkap sesuai cakupan sumber. T15–T27 masih memerlukan pengukuran OP3 tersendiri untuk bagian yang belum terisi.
