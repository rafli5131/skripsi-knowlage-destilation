# Memory — keputusan penggunaan 24 run runtime

Pada 3 November 2026 pengguna menjawab setuju pada langkah penerimaan 24 run untuk **analisis runtime deskriptif** dengan keterbatasan audit yang telah dijelaskan. [Keputusan](../dokumentasi/2026-11-03/percobaan-36-audit-runtime-24-run/KEPUTUSAN_PENGGUNA.md) berlaku untuk penggunaan T36/T37 dalam pembahasan skripsi.

Jangan menyebut kesetaraan kondisi fisik terbukti atau menghapus keterbatasan: urutan blok lintas hari, pemilihan ulang teacher berjalan, dua screenshot sesuai waktu yang tidak tersedia, baseline Hybrid berjalan u1 enam sendi, sebagian status torque dan pengukuran adegan/suhu yang tidak terdokumentasi. Persetujuan pembimbing belum dicatat. Lanjutkan penyusunan Bab IV/V menggunakan T36/T37, T05/T30 dan T35; T38 empat model pada 260 frame OP3 belum dikerjakan dan hanya jika dibutuhkan untuk klaim perbandingan pada frame kamera yang sama.
